   83: =head1 DESCRIPTION
   84: 
   85: Enforces strictly private access on subroutines.  A subroutine decorated
   86: with C<:Private> (or named in C<use Sub::Private qw(...)> when in enforce
   87: mode) may only be called from within its defining package.  Subclasses do
   88: not inherit access: private means I<this package only>.
   89: 
   90: =head2 Two enforcement modes
   91: 
   92: =over 4
   93: 
   94: =item C<namespace> mode (default, backward-compatible)
   95: 
   96: Removes the subroutine from the package symbol table using
   97: L<namespace::clean>.  Direct (non-method) function calls compiled before
   98: cleanup still work because Perl optimises them to direct opcode references.
   99: OO method dispatch (C<$self->name>) does not work for private subs in this
  100: mode because method lookup uses the symbol table at runtime.
  101: 
  102: This is the default mode and is backward-compatible with all existing code.
  103: 
  104: =item C<enforce> mode (OO-safe, opt-in)
  105: 
  106: Replaces the subroutine with a wrapper closure that checks C<caller> at
  107: call time and either delegates (owner package) or croaks (anyone else).
  108: Works correctly with OO dispatch (C<$self->_helper>).
  109: 
  110: Enable it for your package only, in the C<use> line:
  111: 
  112:     package MyClass;
  113:     use Sub::Private { mode => 'enforce' };
  114:     sub _helper :Private { ... }
  115: 
  116: This is the recommended form for modules.  Other packages keep the mode
  117: they chose, or the global C<$Sub::Private::config{mode}>.
  118: 
  119: The older form sets the mode for every package in the program, and must
  120: stay set until C<CHECK>, so it changes how other modules' C<:Private>
  121: subs are handled.  Use it only in a program, not in a module:
  122: 
  123:     BEGIN { $Sub::Private::config{mode} = 'enforce' }
  124:     package MyClass;
  125:     use Sub::Private;
  126:     sub _helper :Private { ... }
  127: 
  128: =back
  129: 
  130: =head2 Behaviour of wrapped subs (enforce mode)
  131: 
  132: =over 4
  133: 
  134: =item * The wrapper hands over with C<goto &sub>, so it does not appear
  135: on the call stack: C<caller> inside a private sub sees its real caller.
  136: 
  137: =item * Arguments, C<@_> aliasing and calling context (list, scalar or
  138: void) are passed through unchanged.
  139: 
  140: =item * C<$_> is left untouched, whether the call is allowed or blocked.
  141: 
  142: =item * A blocked call croaks; it does not fall through to C<AUTOLOAD>.
  143: 
  144: =item * Works with L<Moo> and L<Moose> classes; use the declarative form
  145: after C<use Moo> or C<use Moose>.
  146: 
  147: =back
  148:

  272: =head1 PUBLIC INTERFACE
  273: 
  274: =head2 import
  275: 
  276:     use Sub::Private;                    # attribute form -- no arguments
  277:     use Sub::Private qw(_a _b _c);      # declarative form (enforce mode only)
  278:     use Sub::Private { mode => 'enforce' };              # mode for this package
  279:     use Sub::Private { mode => 'enforce' }, qw(_a _b);   # both
  280: 
  281: =head3 Purpose
  282: 
  283: Called automatically by C<use Sub::Private>.
  284: 
  285: With B<no arguments>: makes the C<:Private> attribute globally available
  286: via C<UNIVERSAL>.  No other action is taken.
  287: 
  288: With B<a hash reference first>: sets options for the calling package
  289: only.  The one option is C<mode>, C<'namespace'> or C<'enforce'>.  It
  290: decides what happens to that package's C<:Private> subs and whether it
  291: may use the declarative form, whatever C<$Sub::Private::config{mode}>
  292: says.  The global mode is not changed, so other packages are not
  293: affected.  The mode applies to subs in the package that made the C<use>
  294: call, so put the C<use> line inside the package.
  295: 
  296: With B<one or more sub names>: registers those named subs in the calling
  297: package for access-enforcement wrapping at C<CHECK> time.  If C<CHECK>
  298: has already fired (for example the package is loaded with C<require> at
  299: run time), the subs are wrapped as soon as the enclosing scope (normally
  300: the rest of the file) has been compiled, so the C<use> line can still
  301: come before the subs it names.  A direct C<< Sub::Private->import(...) >>
  302: call at run time wraps immediately.  Requires the package's mode (see
  303: above), or else C<$Sub::Private::config{mode}>, to equal C<'enforce'>;
  304: croaks otherwise.
  305: 
  306: =head3 Arguments
  307: 
  308: =over 4
  309: 
  310: =item C<\%options> (optional)
  311: 
  312: A hash reference, before any sub names.  The only key allowed is
  313: C<mode>, whose value must be C<'namespace'> or C<'enforce'>.
  314: 
  315: =item C<@subs> (optional)
  316: 
  317: Zero or more Perl sub names.  Each must be a defined, non-reference scalar
  318: matching C</\A[_a-zA-Z]\w*\z/>.  C<undef>, references, empty strings, and
  319: names starting with a digit or containing hyphens are all rejected.
  320: 
  321: =back
  322: 
  323: =head3 Returns
  324: 
  325: The class name (C<'Sub::Private'>) as a plain string in all cases.
  326: 
  327: =head3 Side effects
  328: 
  329: =over 4
  330: 
  331: =item * With C<\%options>: records the mode for the calling package.  A
  332: later call from the same package replaces it.
  333: 
  334: =item * Pre-CHECK: appends C<[$owner_pkg, $sub_name]> pairs to the
  335: internal C<@_pending> list.

  666: =head1 PUBLIC VARIABLES
  667: 
  668: =head2 C<$BYPASS>
  669: 
  670: Set to a true value to disable all access checks (enforce mode only).
  671: Use C<local> in tests; see L</Bypass for testing>.
  672: 
  673: =head2 C<%config>
  674: 
  675: Module-level configuration hash.  Supported keys:
  676: 
  677: =over 4
  678: 
  679: =item C<mode>
  680: 
  681: C<'namespace'> (default) or C<'enforce'>.  Must be set in a C<BEGIN>
  682: block before C<use Sub::Private> to take effect at C<CHECK> time.  It
  683: applies to every package that did not choose its own mode with
  684: C<use Sub::Private { mode => ... }>, so a module should use that form
  685: instead of changing this value.
  686: 
  687: =item C<harness_bypass>
  688: 
  689: When true (default), access checks are skipped whenever
  690: C<$ENV{HARNESS_ACTIVE}> is set.  Set to 0 to test enforcement under
  691: C<prove>.
  692: 
  693: =back
  694: 
  695: =head1 KNOWN LIMITATIONS
  696: 
  697: =over 4
  698: 
  699: =item C<namespace> mode: OO dispatch fails for private subs
  700: 
  701: C<$self->_helper> from within the owner package fails because method
  702: dispatch uses the symbol table at runtime, which no longer contains the
  703: entry.  Use C<enforce> mode for OO classes.
  704: 
  705: =item C<enforce> mode: runtime-only
  706: 
  707: Checks are runtime only; there is no compile-time enforcement.
  708: 
  709: =item C<enforce> mode: raw coderef bypass
  710: 
  711: A raw code reference obtained B<before> wrapping (via C<can()> or
  712: C<\&Foo::_helper>) bypasses the check.  The attribute form makes this
  713: hard because wrapping happens at CHECK time.  When the package is loaded
  714: after CHECK, wrapping happens at the end of the enclosing scope, so a
  715: C<BEGIN> block earlier in the same file could still take a reference to
  716: the unwrapped sub.
  717: 
  718: =item C<enforce> mode: C<can()> leaks private method existence
  719: 
  720: In C<enforce> mode the original sub is replaced by a wrapper closure, so
  721: C<< ->can('_helper') >> returns the wrapper (a true value) even to callers outside
  722: the owner package.  In C<namespace> mode the stash entry is deleted entirely,
  723: so C<< ->can >> correctly returns C<undef>.  A future release may inject a
  724: caller-aware C<can()> override into each class that uses C<enforce> mode,
  725: returning the coderef only when the caller is the owner package and C<undef>
  726: for everyone else.
  727: 
  728: =item Windows Perl 5.42: an undefined declared sub only warns
  729: 
  730: On Windows with Perl 5.42 and later, Sub::Private makes
  731: L<B::Hooks::EndOfScope> use its pure-Perl backend, because the XS one
  732: (L<Variable::Magic>) crashes Perl there as soon as it loads.  The
  733: pure-Perl backend cannot pass an exception out of a scope-end callback.
  734: So when a package that is loaded at run time (after C<CHECK>) names an
  735: undefined sub in C<use Sub::Private qw(...)>, the "is not defined"
  736: error is printed as a warning and loading continues, instead of
  737: C<require> dying.  Everywhere else it still croaks.  Set
  738: C<B_HOOKS_ENDOFSCOPE_IMPLEMENTATION> yourself to choose the backend.
  739: 
  740: =item UNIVERSAL namespace pollution
  741: 
  742: The C<:Private> attribute is installed in C<UNIVERSAL>, which is
  743: intentional (any package can use it after a single C<use>), but it does
  744: introduce C<UNIVERSAL::Private> into the global namespace.
  745: 
  746: =back

  778: =head1 FORMAL SPECIFICATION
  779: 
  780: The following Z-notation schemas formally specify the C<CheckAccess>
  781: operation and C<import>.
  782: 
  783: =head2 C<CheckAccess>
  784: 
  785:     -- Type abbreviations
  786:     Package  == seq CHAR     -- a non-empty Perl package name string
  787:     SubName  == seq CHAR     -- a Perl identifier string
  788: 
  789:     -- Private-access predicate (strictly owner only -- no isa expansion)
  790:     permitted : Package x Package -> BOOL
  791:     forall caller, owner : Package .
  792:         permitted(caller, owner) <=> caller = owner
  793: 
  794:     -- System state
  795:     +-Registry-------------------------------------------+
  796:     | private   : P (Package x SubName)                  |
  797:     | bypass    : BOOL                                    |
  798:     | config    : { mode : seq CHAR,                      |
  799:     |               harness_bypass : BOOL }               |
  800:     | pkg_mode  : Package -+> seq CHAR                   |
  801:     +----------------------------------------------------+
  802: 
  803:     -- Initial state
  804:     +-InitRegistry---------------------------------------+
  805:     | Registry                                           |
  806:     |----------------------------------------------------|
  807:     | private   = {}                                     |
  808:     | bypass    = false                                  |
  809:     | config    = { mode |-> 'namespace',                 |
  810:     |               harness_bypass |-> true }             |
  811:     | pkg_mode  = {}                                     |
  812:     +----------------------------------------------------+
  813: 
  814:     -- Bypass predicate
  815:     bypass_active(R) <=>
  816:         R.bypass or (R.config.harness_bypass and HARNESS_ACTIVE)
  817: 
  818:     -- Access check: no state change
  819:     +-CheckAccess----------------------------------------+
  820:     | Xi-Registry                                        |
  821:     | caller? : Package                                  |
  822:     | owner?  : Package                                  |
  823:     | name?   : SubName                                  |
  824:     | ok!     : BOOL                                     |
  825:     |----------------------------------------------------|
  826:     | (owner?, name?) in private                         |
  827:     | ok! <=> bypass_active or permitted(caller?, owner?)|
  828:     +----------------------------------------------------+
  829: 
  830:     -- Violation (croak case):
  831:     --   not ok! =>
  832:     --   croak("name?()" ++ " is a private subroutine of " ++ owner?
  833:     --         ++ " and cannot be called from " ++ caller?)
  834: 
  835:     -- Key difference from Sub::Protected:
  836:     --   permitted(caller, owner) <=> caller = owner   (identity only)
  837:     -- vs Sub::Protected:
  838:     --   permitted(caller, owner) <=> owner in anc(caller)   (ISA chain)
  839: 
  840: =head2 import
  841: 
  842:     -- Valid identifier predicate
  843:     valid_id : SubName -> BOOL
  844:     valid_id(n) <=> n =~ /\A[_a-zA-Z]\w*\z/
  845: 
  846:     -- Compile phase: CHECK has run, and code is still being compiled
  847:     post_check  : BOOL
  848:     compiling   : BOOL       -- true while $^S is undefined
  849: 
  850:     -- The mode that applies to a package's subs
  851:     mode_for(p) = pkg_mode(p)   if p in dom pkg_mode
  852:                 = config.mode   otherwise
  853: 
  854:     -- Options (hashref first): sets the caller's mode only
  855:     +-ImportOptions-------------------------------------+
  856:     | Delta-Registry                                    |
  857:     | mode? : seq CHAR                                  |
  858:     |---------------------------------------------------|
  859:     | mode? in { 'namespace', 'enforce' }               |
  860:     | pkg_mode' = pkg_mode (+) { caller |-> mode? }     |
  861:     | config' = config                                  |
  862:     +---------------------------------------------------+
  863: 
  864:     -- Pre-condition (declarative form)
  865:     +-ImportPre-----------------------------------------+
  866:     | mode_for(caller) = 'enforce'                      |
  867:     | forall n in subs . valid_id(n)                    |
  868:     +---------------------------------------------------+
  869: 
  870:     -- Post-condition (before CHECK): queue for the CHECK block
  871:     +-ImportPost_PreCheck-------------------------------+
  872:     | not post_check                                    |
  873:     |---------------------------------------------------|
  874:     | pending' = pending ++ < (caller, n) | n in subs > |
  875:     +---------------------------------------------------+
  876: 
  877:     -- Post-condition (after CHECK, at run time): wrap now
  878:     +-ImportPost_RunTime--------------------------------+
  879:     | post_check and not compiling                      |
  880:     | forall n in subs . defined(caller, n)             |
  881:     |---------------------------------------------------|
  882:     | forall n in subs .                                |
  883:     |   stash'(caller, n) = wrapper(caller, n)          |
  884:     +---------------------------------------------------+
  885: 
  886:     -- Post-condition (after CHECK, while compiling): wrap at the
  887:     -- end of the enclosing scope S
  888:     +-ImportPost_Deferred-------------------------------+
  889:     | post_check and compiling                          |
  890:     |---------------------------------------------------|
  891:     | at end_of_scope(S) :                              |
  892:     |   (forall n in subs . defined(caller, n)) =>      |
  893:     |     forall n in subs .                            |
  894:     |       stash'(caller, n) = wrapper(caller, n)      |
  895:     |   (exists n in subs . not defined(caller, n)) =>  |
  896:     |     croak at the "use" line                       |
  897:     +---------------------------------------------------+
  898: 
  899:     -- In every case, a sub that is not defined when wrapping is
  900:     -- attempted croaks:
  901:     --   "Sub::Private: " ++ caller ++ "::" ++ n ++ " is not defined"
