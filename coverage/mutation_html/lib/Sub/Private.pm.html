  533: =head1 KNOWN LIMITATIONS
  534: 
  535: =over 4
  536: 
  537: =item C<namespace> mode: OO dispatch fails for private subs
  538: 
  539: C<$self->_helper> from within the owner package fails because method
  540: dispatch uses the symbol table at runtime, which no longer contains the
  541: entry.  Use C<enforce> mode for OO classes.
  542: 
  543: =item Loading after C<CHECK> needs Perl 5.14
  544: 
  545: Packages loaded at run time (C<require>, a plugin loader, a string
  546: C<eval>) are protected only on Perl 5.14 or later, which provides
  547: C<${^GLOBAL_PHASE}>.  On older Perls, load C<Sub::Private> and the
  548: packages that use it at compile time (C<use>, or C<require> inside
  549: C<BEGIN>); otherwise their private subs are left unprotected.
  550: 
  551: =item C<enforce> mode: runtime-only
  552: 
  553: Checks are runtime only; there is no compile-time enforcement.
  554: 
  555: =item C<enforce> mode: raw coderef bypass
  556: 
  557: A raw code reference obtained B<before> wrapping (via C<can()> or
  558: C<\&Foo::_helper>) bypasses the check.  The attribute form prevents this
  559: because wrapping happens at CHECK time.
  560: 
  561: =item C<enforce> mode: C<can()> leaks private method existence
  562: 
  563: In C<enforce> mode the original sub is replaced by a wrapper closure, so
  564: C<< ->can('_helper') >> returns the wrapper (truthy) even to callers outside
  565: the owner package.  In C<namespace> mode the stash entry is deleted entirely,
  566: so C<< ->can >> correctly returns C<undef>.  A future release may inject a
  567: caller-aware C<can()> override into each class that uses C<enforce> mode,
  568: returning the coderef only when the caller is the owner package and C<undef>
  569: for everyone else.
  570: 
  571: =item UNIVERSAL namespace pollution
  572: 
  573: The C<:Private> attribute is installed in C<UNIVERSAL>, which is
  574: intentional (any package can use it after a single C<use>), but it does
  575: introduce C<UNIVERSAL::Private> into the global namespace.
  576: 
  577: =back

  607: =head1 FORMAL SPECIFICATION
  608: 
  609: The following Z-notation schemas formally specify the C<CheckAccess>
  610: operation.
  611: 
  612:     -- Type abbreviations
  613:     Package  == seq CHAR     -- a non-empty Perl package name string
  614:     SubName  == seq CHAR     -- a Perl identifier string
  615: 
  616:     -- Private-access predicate (strictly owner only -- no isa expansion)
  617:     permitted : Package x Package -> BOOL
  618:     forall caller, owner : Package .
  619:         permitted(caller, owner) <=> caller = owner
  620: 
  621:     -- System state
  622:     +-Registry-------------------------------------------+
  623:     | private   : P (Package x SubName)                  |
  624:     | bypass    : BOOL                                    |
  625:     | config    : { mode : seq CHAR,                      |
  626:     |               harness_bypass : BOOL }               |
  627:     +----------------------------------------------------+
  628: 
  629:     -- Initial state
  630:     +-InitRegistry---------------------------------------+
  631:     | Registry                                           |
  632:     |----------------------------------------------------|
  633:     | private   = {}                                     |
  634:     | bypass    = false                                  |
  635:     | config    = { mode |-> 'namespace',                 |
  636:     |               harness_bypass |-> true }             |
  637:     +----------------------------------------------------+
  638: 
  639:     -- Bypass predicate
  640:     bypass_active(R) <=>
  641:         R.bypass or (R.config.harness_bypass and HARNESS_ACTIVE)
  642: 
  643:     -- Access check: no state change
  644:     +-CheckAccess----------------------------------------+
  645:     | Xi-Registry                                        |
  646:     | caller? : Package                                  |
  647:     | owner?  : Package                                  |
  648:     | name?   : SubName                                  |
  649:     | ok!     : BOOL                                     |
  650:     |----------------------------------------------------|
  651:     | (owner?, name?) in private                         |
  652:     | ok! <=> bypass_active or permitted(caller?, owner?)|
  653:     +----------------------------------------------------+
  654: 
  655:     -- Violation (croak case):
  656:     --   not ok! =>
  657:     --   croak("name?()" ++ " is a private subroutine of " ++ owner?
  658:     --         ++ " and cannot be called from " ++ caller?)
  659: 
  660:     -- Key difference from Sub::Protected:
  661:     --   permitted(caller, owner) <=> caller = owner   (identity only)
  662:     -- vs Sub::Protected:
  663:     --   permitted(caller, owner) <=> owner in anc(caller)   (ISA chain)
