   69: =head1 DESCRIPTION
   70: 
   71: Enforces strictly private access on subroutines.  A subroutine decorated
   72: with C<:Private> (or named in C<use Sub::Private qw(...)> when in enforce
   73: mode) may only be called from within its defining package.  Subclasses do
   74: not inherit access: private means I<this package only>.
   75: 
   76: =head2 Two enforcement modes
   77: 
   78: =over 4
   79: 
   80: =item C<namespace> mode (default, backward-compatible)
   81: 
   82: Removes the subroutine from the package symbol table using
   83: L<namespace::clean>.  Direct (non-method) function calls compiled before
   84: cleanup still work because Perl optimises them to direct opcode references.
   85: OO method dispatch (C<$self->name>) does not work for private subs in this
   86: mode because method lookup uses the symbol table at runtime.
   87: 
   88: This is the default mode and is backward-compatible with all existing code.
   89: 
   90: =item C<enforce> mode (OO-safe, opt-in)
   91: 
   92: Replaces the subroutine with a wrapper closure that checks C<caller> at
   93: call time and either delegates (owner package) or croaks (anyone else).
   94: Works correctly with OO dispatch (C<$self->_helper>).
   95: 
   96: Enable before declaring your first private sub:
   97: 
   98:     BEGIN { $Sub::Private::config{mode} = 'enforce' }
   99:     package MyClass;
  100:     use Sub::Private;
  101:     sub _helper :Private { ... }
  102: 
  103: =back
  104: 
  105: =head2 Behaviour of wrapped subs (enforce mode)
  106: 
  107: =over 4
  108: 
  109: =item * The wrapper hands over with C<goto &sub>, so it does not appear
  110: on the call stack: C<caller> inside a private sub sees its real caller.
  111: 
  112: =item * Arguments, C<@_> aliasing and calling context (list, scalar or
  113: void) are passed through unchanged.
  114: 
  115: =item * C<$_> is left untouched, whether the call is allowed or blocked.
  116: 
  117: =item * A blocked call croaks; it does not fall through to C<AUTOLOAD>.
  118: 
  119: =item * Works with L<Moo> and L<Moose> classes; use the declarative form

  122: =back

  548: 
  549: =over 4
  550: 
  551: =item C<mode>
  552: 
  553: C<'namespace'> (default) or C<'enforce'>.  Must be set in a C<BEGIN>
  554: block before C<use Sub::Private> to take effect at C<CHECK> time.
  555: 
  556: =item C<harness_bypass>
  557: 
  558: When true (default), access checks are skipped whenever
  559: C<$ENV{HARNESS_ACTIVE}> is set.  Set to 0 to test enforcement under
  560: C<prove>.
  561: 
  562: =back
  563: 
  564: =head1 KNOWN LIMITATIONS
  565: 
  566: =over 4
  567: 
  568: =item C<namespace> mode: OO dispatch fails for private subs
  569: 
  570: C<$self->_helper> from within the owner package fails because method
  571: dispatch uses the symbol table at runtime, which no longer contains the
  572: entry.  Use C<enforce> mode for OO classes.
  573: 
  574: =item C<enforce> mode: runtime-only
  575: 
  576: Checks are runtime only; there is no compile-time enforcement.
  577: 
  578: =item C<enforce> mode: raw coderef bypass
  579: 
  580: A raw code reference obtained B<before> wrapping (via C<can()> or
  581: C<\&Foo::_helper>) bypasses the check.  The attribute form makes this
  582: hard because wrapping happens at CHECK time.  When the package is loaded
  583: after CHECK, wrapping happens at the end of the enclosing scope, so a
  584: C<BEGIN> block earlier in the same file could still take a reference to
  585: the unwrapped sub.
  586: 
  587: =item C<enforce> mode: C<can()> leaks private method existence
  588: 
  589: In C<enforce> mode the original sub is replaced by a wrapper closure, so
  590: C<< ->can('_helper') >> returns the wrapper (a true value) even to callers outside
  591: the owner package.  In C<namespace> mode the stash entry is deleted entirely,
  592: so C<< ->can >> correctly returns C<undef>.  A future release may inject a
  593: caller-aware C<can()> override into each class that uses C<enforce> mode,
  594: returning the coderef only when the caller is the owner package and C<undef>
  595: for everyone else.
  596: 
  597: =item UNIVERSAL namespace pollution
  598: 
  599: The C<:Private> attribute is installed in C<UNIVERSAL>, which is
  600: intentional (any package can use it after a single C<use>), but it does
  601: introduce C<UNIVERSAL::Private> into the global namespace.
  602: 
  603: =back

  635: =head1 FORMAL SPECIFICATION
  636: 
  637: The following Z-notation schemas formally specify the C<CheckAccess>
  638: operation and C<import>.
  639: 
  640: =head2 C<CheckAccess>
  641: 
  642:     -- Type abbreviations
  643:     Package  == seq CHAR     -- a non-empty Perl package name string
  644:     SubName  == seq CHAR     -- a Perl identifier string
  645: 
  646:     -- Private-access predicate (strictly owner only -- no isa expansion)
  647:     permitted : Package x Package -> BOOL
  648:     forall caller, owner : Package .
  649:         permitted(caller, owner) <=> caller = owner
  650: 
  651:     -- System state
  652:     +-Registry-------------------------------------------+
  653:     | private   : P (Package x SubName)                  |
  654:     | bypass    : BOOL                                    |
  655:     | config    : { mode : seq CHAR,                      |
  656:     |               harness_bypass : BOOL }               |
  657:     +----------------------------------------------------+
  658: 
  659:     -- Initial state
  660:     +-InitRegistry---------------------------------------+
  661:     | Registry                                           |
  662:     |----------------------------------------------------|
  663:     | private   = {}                                     |
  664:     | bypass    = false                                  |
  665:     | config    = { mode |-> 'namespace',                 |
  666:     |               harness_bypass |-> true }             |
  667:     +----------------------------------------------------+
  668: 
  669:     -- Bypass predicate
  670:     bypass_active(R) <=>
  671:         R.bypass or (R.config.harness_bypass and HARNESS_ACTIVE)
  672: 
  673:     -- Access check: no state change
  674:     +-CheckAccess----------------------------------------+
  675:     | Xi-Registry                                        |
  676:     | caller? : Package                                  |
  677:     | owner?  : Package                                  |
  678:     | name?   : SubName                                  |
  679:     | ok!     : BOOL                                     |
  680:     |----------------------------------------------------|
  681:     | (owner?, name?) in private                         |
  682:     | ok! <=> bypass_active or permitted(caller?, owner?)|
  683:     +----------------------------------------------------+
  684: 
  685:     -- Violation (croak case):
  686:     --   not ok! =>
  687:     --   croak("name?()" ++ " is a private subroutine of " ++ owner?
  688:     --         ++ " and cannot be called from " ++ caller?)
  689: 
  690:     -- Key difference from Sub::Protected:
  691:     --   permitted(caller, owner) <=> caller = owner   (identity only)
  692:     -- vs Sub::Protected:
  693:     --   permitted(caller, owner) <=> owner in anc(caller)   (ISA chain)
  694: 
  695: =head2 import
  696: 
  697:     -- Valid identifier predicate
  698:     valid_id : SubName -> BOOL
  699:     valid_id(n) <=> n =~ /\A[_a-zA-Z]\w*\z/
  700: 
  701:     -- Compile phase: CHECK has run, and code is still being compiled
  702:     post_check  : BOOL
  703:     compiling   : BOOL       -- true while $^S is undefined
  704: 
  705:     -- Pre-condition (declarative form)
  706:     +-ImportPre-----------------------------------------+
  707:     | config.mode = 'enforce'                           |
  708:     | forall n in subs . valid_id(n)                    |
  709:     +---------------------------------------------------+
  710: 
  711:     -- Post-condition (before CHECK): queue for the CHECK block
  712:     +-ImportPost_PreCheck-------------------------------+
  713:     | not post_check                                    |
  714:     |---------------------------------------------------|
  715:     | pending' = pending ++ < (caller, n) | n in subs > |
  716:     +---------------------------------------------------+
  717: 
  718:     -- Post-condition (after CHECK, at run time): wrap now
  719:     +-ImportPost_RunTime--------------------------------+
  720:     | post_check and not compiling                      |
  721:     | forall n in subs . defined(caller, n)             |
  722:     |---------------------------------------------------|
  723:     | forall n in subs .                                |
  724:     |   stash'(caller, n) = wrapper(caller, n)          |
  725:     +---------------------------------------------------+
  726: 
  727:     -- Post-condition (after CHECK, while compiling): wrap at the
  728:     -- end of the enclosing scope S
  729:     +-ImportPost_Deferred-------------------------------+
  730:     | post_check and compiling                          |
  731:     |---------------------------------------------------|
  732:     | at end_of_scope(S) :                              |
  733:     |   (forall n in subs . defined(caller, n)) =>      |
  734:     |     forall n in subs .                            |
  735:     |       stash'(caller, n) = wrapper(caller, n)      |
  736:     |   (exists n in subs . not defined(caller, n)) =>  |
  737:     |     croak at the "use" line                       |
  738:     +---------------------------------------------------+
  739: 
  740:     -- In every case, a sub that is not defined when wrapping is
  741:     -- attempted croaks:
  742:     --   "Sub::Private: " ++ caller ++ "::" ++ n ++ " is not defined"
