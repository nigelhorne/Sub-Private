  175: =head1 DESCRIPTION
  176: 
  177: Enforces strictly private access on subroutines.  A subroutine decorated
  178: with C<:Private> (or named in C<use Sub::Private qw(...)> when in enforce
  179: mode) may only be called from within its defining package.  Subclasses do
  180: not inherit access: private means I<this package only>.
  181: 
  182: =head2 Two enforcement modes
  183: 
  184: =over 4
  185: 
  186: =item C<namespace> mode (default, backward-compatible)
  187: 
  188: Removes the subroutine from the package symbol table using
  189: L<namespace::clean>.  Direct (non-method) function calls compiled before
  190: cleanup still work because Perl optimises them to direct opcode references.
  191: OO method dispatch (C<$self->name>) does not work for private subs in this
  192: mode because method lookup uses the symbol table at runtime.
  193: 
  194: This is the default mode and is backward-compatible with all existing code.
  195: 
  196: =item C<enforce> mode (OO-safe, opt-in)
  197: 
  198: Replaces the subroutine with a wrapper closure that checks C<caller> at
  199: call time and either delegates (owner package) or croaks (anyone else).
  200: Works correctly with OO dispatch (C<$self->_helper>).
  201: 
  202: Enable before declaring your first private sub:
  203: 
  204:     BEGIN { $Sub::Private::config{mode} = 'enforce' }
  205:     package MyClass;
  206:     use Sub::Private;
  207:     sub _helper :Private { ... }
  208: 
  209: =back

  539: 		croak "${sub_name}() is a private subroutine of ${owner_pkg}"
  540: 			. " and cannot be called from ${pkg}";
  541: 	}
  542: }
  543: 
  544: # _assert_private_caller
  545: # Purpose      : Croak if a guarded private method was called from outside
  546: #                Sub::Private.
  547: # Entry        : $method_name -- the guarded method name (for error messages)
  548: # Exit status  : Returns normally if caller(1) is Sub::Private; croaks
  549: #                otherwise with a descriptive message.
  550: # Notes        : caller(1) is the package that called the guarded method,
  551: #                which in turn called this function.
  552: sub _assert_private_caller {
  553: 	my ($method_name) = @_;
  554: 
  555: 	# caller(1): the package one frame above the guarded method.
  556: 	my $caller = (caller(1))[0] // q{};
  557: 
  558: 	# Only calls originating within Sub::Private itself are permitted.
  559: 	return if $caller eq $SELF;
  560: 
  561: 	croak "${method_name}() is a private method of $SELF"
  562: 		. " and cannot be called from ${caller}";
  563: }
  564: 
  565: 1;
  566: 
  567: __END__

  569: =head1 PUBLIC VARIABLES
  570: 
  571: =head2 C<$BYPASS>
  572: 
  573: Set to a true value to disable all access checks (enforce mode only).
  574: Use C<local> in tests; see L</Bypass for testing>.
  575: 
  576: =head2 C<%config>
  577: 
  578: Module-level configuration hash.  Supported keys:
  579: 
  580: =over 4
  581: 
  582: =item C<mode>
  583: 
  584: C<'namespace'> (default) or C<'enforce'>.  Must be set in a C<BEGIN>
  585: block before C<use Sub::Private> to take effect at C<CHECK> time.
  586: 
  587: =item C<harness_bypass>
  588: 
  589: When true (default), access checks are skipped whenever
  590: C<$ENV{HARNESS_ACTIVE}> is set.  Set to 0 to test enforcement under
  591: C<prove>.
  592: 
  593: =back
  594: 
  595: =head1 KNOWN LIMITATIONS
  596: 
  597: =over 4
  598: 
  599: =item C<namespace> mode: OO dispatch fails for private subs
  600: 
  601: C<$self->_helper> from within the owner package fails because method
  602: dispatch uses the symbol table at runtime, which no longer contains the
  603: entry.  Use C<enforce> mode for OO classes.
  604: 
  605: =item C<enforce> mode: runtime-only
  606: 
  607: Checks are runtime only; there is no compile-time enforcement.
  608: 
  609: =item C<enforce> mode: raw coderef bypass
  610: 
  611: A raw code reference obtained B<before> wrapping (via C<can()> or
  612: C<\&Foo::_helper>) bypasses the check.  The attribute form prevents this
  613: because wrapping happens at CHECK time.
  614: 
  615: =item C<enforce> mode: C<can()> leaks private method existence
  616: 
  617: In C<enforce> mode the original sub is replaced by a wrapper closure, so
  618: C<< ->can('_helper') >> returns the wrapper (truthy) even to callers outside
  619: the owner package.  In C<namespace> mode the stash entry is deleted entirely,
  620: so C<< ->can >> correctly returns C<undef>.  A future release may inject a
  621: caller-aware C<can()> override into each class that uses C<enforce> mode,
  622: returning the coderef only when the caller is the owner package and C<undef>
  623: for everyone else.
  624: 
  625: =item UNIVERSAL namespace pollution
  626: 
  627: The C<:Private> attribute is installed in C<UNIVERSAL>, which is
  628: intentional (any package can use it after a single C<use>), but it does
  629: introduce C<UNIVERSAL::Private> into the global namespace.
  630: 
  631: =back

  661: =head1 FORMAL SPECIFICATION
  662: 
  663: The following Z-notation schemas formally specify the C<CheckAccess>
  664: operation.
  665: 
  666:     -- Type abbreviations
  667:     Package  == seq CHAR     -- a non-empty Perl package name string
  668:     SubName  == seq CHAR     -- a Perl identifier string
  669: 
  670:     -- Private-access predicate (strictly owner only -- no isa expansion)
  671:     permitted : Package x Package -> BOOL
  672:     forall caller, owner : Package .
  673:         permitted(caller, owner) <=> caller = owner
  674: 
  675:     -- System state
  676:     +-Registry-------------------------------------------+
  677:     | private   : P (Package x SubName)                  |
  678:     | bypass    : BOOL                                    |
  679:     | config    : { mode : seq CHAR,                      |
  680:     |               harness_bypass : BOOL }               |
  681:     +----------------------------------------------------+
  682: 
  683:     -- Initial state
  684:     +-InitRegistry---------------------------------------+
  685:     | Registry                                           |
  686:     |----------------------------------------------------|
  687:     | private   = {}                                     |
  688:     | bypass    = false                                  |
  689:     | config    = { mode |-> 'namespace',                 |
  690:     |               harness_bypass |-> true }             |
  691:     +----------------------------------------------------+
  692: 
  693:     -- Bypass predicate
  694:     bypass_active(R) <=>
  695:         R.bypass or (R.config.harness_bypass and HARNESS_ACTIVE)
  696: 
  697:     -- Access check: no state change
  698:     +-CheckAccess----------------------------------------+
  699:     | Xi-Registry                                        |
  700:     | caller? : Package                                  |
  701:     | owner?  : Package                                  |
  702:     | name?   : SubName                                  |
  703:     | ok!     : BOOL                                     |
  704:     |----------------------------------------------------|
  705:     | (owner?, name?) in private                         |
  706:     | ok! <=> bypass_active or permitted(caller?, owner?)|
  707:     +----------------------------------------------------+
  708: 
  709:     -- Violation (croak case):
  710:     --   not ok! =>
  711:     --   croak("name?()" ++ " is a private subroutine of " ++ owner?
  712:     --         ++ " and cannot be called from " ++ caller?)
  713: 
  714:     -- Key difference from Sub::Protected:
  715:     --   permitted(caller, owner) <=> caller = owner   (identity only)
  716:     -- vs Sub::Protected:
  717:     --   permitted(caller, owner) <=> owner in anc(caller)   (ISA chain)
