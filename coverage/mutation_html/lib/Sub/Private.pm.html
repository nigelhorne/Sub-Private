   73: =head1 DESCRIPTION
   74: 
   75: Enforces strictly private access on subroutines.  A subroutine decorated
   76: with C<:Private> (or named in C<use Sub::Private qw(...)> when in enforce
   77: mode) may only be called from within its defining package.  Subclasses do
   78: not inherit access: private means I<this package only>.
   79: 
   80: =head2 Two enforcement modes
   81: 
   82: =over 4
   83: 
   84: =item C<namespace> mode (default, backward-compatible)
   85: 
   86: Removes the subroutine from the package symbol table using
   87: L<namespace::clean>.  Direct (non-method) function calls compiled before
   88: cleanup still work because Perl optimises them to direct opcode references.
   89: OO method dispatch (C<$self->name>) does not work for private subs in this
   90: mode because method lookup uses the symbol table at runtime.
   91: 
   92: This is the default mode and is backward-compatible with all existing code.
   93: 
   94: =item C<enforce> mode (OO-safe, opt-in)
   95: 
   96: Replaces the subroutine with a wrapper closure that checks C<caller> at
   97: call time and either delegates (owner package) or croaks (anyone else).
   98: Works correctly with OO dispatch (C<$self->_helper>).
   99: 
  100: Enable it for your package only, in the C<use> line:
  101: 
  102:     package MyClass;
  103:     use Sub::Private { mode => 'enforce' };
  104:     sub _helper :Private { ... }
  105: 
  106: This is the recommended form for modules.  Other packages keep the mode
  107: they chose, or the global C<$Sub::Private::config{mode}>.
  108: 
  109: The older form sets the mode for every package in the program, and must
  110: stay set until C<CHECK>, so it changes how other modules' C<:Private>
  111: subs are handled.  Use it only in a program, not in a module:
  112: 
  113:     BEGIN { $Sub::Private::config{mode} = 'enforce' }
  114:     package MyClass;
  115:     use Sub::Private;
  116:     sub _helper :Private { ... }
  117: 
  118: =back
  119:

  121: 
  122: =over 4
  123: 
  124: =item * The wrapper hands over with C<goto &sub>, so it does not appear
  125: on the call stack: C<caller> inside a private sub sees its real caller.

  127: =item * Arguments, C<@_> aliasing and calling context (list, scalar or

  271: =head3 Purpose
  272: 
  273: Called automatically by C<use Sub::Private>.
  274: 
  275: With B<no arguments>: makes the C<:Private> attribute globally available
  276: via C<UNIVERSAL>.  No other action is taken.
  277: 
  278: With B<a hash reference first>: sets options for the calling package
  279: only.  The one option is C<mode>, C<'namespace'> or C<'enforce'>.  It
  280: decides what happens to that package's C<:Private> subs and whether it
  281: may use the declarative form, whatever C<$Sub::Private::config{mode}>
  282: says.  The global mode is not changed, so other packages are not
  283: affected.  The mode applies to subs in the package that made the C<use>
  284: call, so put the C<use> line inside the package.
  285: 
  286: With B<one or more sub names>: registers those named subs in the calling
  287: package for access-enforcement wrapping at C<CHECK> time.  If C<CHECK>
  288: has already fired (for example the package is loaded with C<require> at
  289: run time), the subs are wrapped as soon as the enclosing scope (normally
  290: the rest of the file) has been compiled, so the C<use> line can still
  291: come before the subs it names.  A direct C<< Sub::Private->import(...) >>
  292: call at run time wraps immediately.  Requires the package's mode (see
  293: above), or else C<$Sub::Private::config{mode}>, to equal C<'enforce'>;
  294: croaks otherwise.
  295:

  297: 
  298: =over 4
  299:

  547: 	my ($owner_pkg, $sub_name) = @_;
  548: 
  549: 	# Guard: only Sub::Private itself may call this.
  550: 	_assert_private_caller('_process_one')
  551: 		unless $BYPASS || ($config{$KEY_HARNESS_BYPASS} && $ENV{HARNESS_ACTIVE});
  552: 
  553: 	no strict 'refs';	## no critic (ProhibitNoStrict)
  554: 
  555: 	# Ensure the target sub exists in the stash before wrapping.
  556: 	croak "$SELF: ${owner_pkg}::${sub_name} is not defined"
  557: 		unless defined &{"${owner_pkg}::${sub_name}"};
  558: 
  559: 	my $code = \&{"${owner_pkg}::${sub_name}"};
  560: 
  561: 	# Replace the stash entry with the enforcement wrapper.
  562: 	no warnings 'redefine';
  563: 	*{"${owner_pkg}::${sub_name}"} = _wrap($owner_pkg, $sub_name, $code);
  564: 	return;
  565: }
  566: 
  567: # _wrap
  568: # Purpose      : Build an enforcement wrapper closure around a coderef.
  569: # Entry        : $owner_pkg -- the package that owns the private sub
  570: #                $sub_name  -- the unqualified sub name (for error messages)
  571: #                $code      -- the original coderef to delegate to
  572: # Exit status  : Returns a new coderef that enforces the private-access rule.
  573: # Side effects : none (variables captured by closure)
  574: # Notes        : goto &$code is used rather than $code->(@_) so that caller()
  575: #                inside the private sub sees the real caller, not Sub::Private.
  576: #                This is load-bearing: removing it breaks tests that inspect
  577: #                caller() inside a private sub.  Guarded by _assert_private_caller.
  578: sub _wrap {
  579: 	my ($owner_pkg, $sub_name, $code) = @_;
  580: 
  581: 	# Guard: only Sub::Private itself may call this.
  582: 	_assert_private_caller('_wrap')
  583: 		unless $BYPASS || ($config{$KEY_HARNESS_BYPASS} && $ENV{HARNESS_ACTIVE});
  584: 
  585: 	# Capture the three args in the closure; the wrapper has no mutable state.
  586: 	return sub {
  587: 		Sub::Private::_check_access($owner_pkg, $sub_name);
  588: 		goto &$code;    ## no critic (ControlStructures::ProhibitGoto)
  589: 	};
  590: }
  591: 
  592: # _check_access
  593: # Purpose      : Enforce the private-access invariant at call time.
  594: # Entry        : $owner_pkg -- the package that owns the private sub
  595: #                $sub_name  -- unqualified sub name (for error messages)
  596: # Exit status  : Returns normally if the immediate non-Sub::Private caller is
  597: #                the owner package.  Croaks if any other package is found first.
  598: # Notes        : Unlike Sub::Protected there is NO ->isa check.  Private means
  599: #                the owner package ONLY; subclasses are blocked.
  600: #                The stack walk skips Sub::Private frames so the wrapper is
  601: #                transparent to the check.
  602: sub _check_access {
●603 → 611 → 0  603: 	my ($owner_pkg, $sub_name) = @_;
  604: 
  605: 	# Fast bypass paths: either condition alone disables all checks (OR logic).
  606: 	return if $BYPASS;
  607: 	return if $config{$KEY_HARNESS_BYPASS} && $ENV{HARNESS_ACTIVE};
  608: 
  609: 	# Walk the call stack, skipping Sub::Private wrapper frames.
  610: 	my $frame = 0;
  611: 	while (1) {
  612: 		my $pkg = (caller($frame))[0];
  613: 
  614: 		# Reached the bottom of the stack with no valid caller found.
  615: 		if (!defined $pkg) {
  616: 			croak "${sub_name}() is a private subroutine of ${owner_pkg}"
  617: 				. ' and cannot be called from outside any package';
  618: 		}
  619: 
  620: 		# Skip any Sub::Private frames (e.g., the wrapper closure itself).
  621: 		$frame++, next if $pkg eq $SELF;
  622: 
  623: 		# The first non-Sub::Private caller must be the owner; everyone else
  624: 		# is blocked -- no isa allowance, unlike Sub::Protected.
  625: 		return if $pkg eq $owner_pkg;
  626: 		croak "${sub_name}() is a private subroutine of ${owner_pkg}"
  627: 			. " and cannot be called from ${pkg}";
  628: 	}
  629: }
  630: 
  631: # _assert_private_caller
  632: # Purpose      : Croak if a guarded private method was called from outside
  633: #                Sub::Private.
  634: # Entry        : $method_name -- the guarded method name (for error messages)
  635: # Exit status  : Returns normally if caller(1) is Sub::Private; croaks
  636: #                otherwise with a descriptive message.
  637: # Notes        : caller(1) is the package that called the guarded method,
  638: #                which in turn called this function.
  639: sub _assert_private_caller {
  640: 	my ($method_name) = @_;
  641: 
  642: 	# caller(1): the package one frame above the guarded method.
  643: 	my $caller = (caller(1))[0] // q{};
  644: 
  645: 	# Only calls originating within Sub::Private itself are permitted.
  646: 	return if $caller eq $SELF;
  647: 
  648: 	croak "${method_name}() is a private method of $SELF"
  649: 		. " and cannot be called from ${caller}";
  650: }

  656: =head1 PUBLIC VARIABLES
  657: 
  658: =head2 C<$BYPASS>
  659: 
  660: Set to a true value to disable all access checks (enforce mode only).
  661: Use C<local> in tests; see L</Bypass for testing>.
  662: 
  663: =head2 C<%config>
  664: 
  665: Module-level configuration hash.  Supported keys:
  666: 
  667: =over 4
  668: 
  669: =item C<mode>
  670: 
  671: C<'namespace'> (default) or C<'enforce'>.  Must be set in a C<BEGIN>
  672: block before C<use Sub::Private> to take effect at C<CHECK> time.  It
  673: applies to every package that did not choose its own mode with
  674: C<use Sub::Private { mode => ... }>, so a module should use that form
  675: instead of changing this value.
  676: 
  677: =item C<harness_bypass>
  678: 
  679: When true (default), access checks are skipped whenever
  680: C<$ENV{HARNESS_ACTIVE}> is set.  Set to 0 to test enforcement under
  681: C<prove>.
  682: 
  683: =back
  684: 
  685: =head1 KNOWN LIMITATIONS
  686: 
  687: =over 4
  688: 
  689: =item C<namespace> mode: OO dispatch fails for private subs
  690: 
  691: C<$self->_helper> from within the owner package fails because method
  692: dispatch uses the symbol table at runtime, which no longer contains the
  693: entry.  Use C<enforce> mode for OO classes.
  694: 
  695: =item C<enforce> mode: runtime-only
  696: 
  697: Checks are runtime only; there is no compile-time enforcement.
  698: 
  699: =item C<enforce> mode: raw coderef bypass
  700: 
  701: A raw code reference obtained B<before> wrapping (via C<can()> or
  702: C<\&Foo::_helper>) bypasses the check.  The attribute form makes this
  703: hard because wrapping happens at CHECK time.  When the package is loaded
  704: after CHECK, wrapping happens at the end of the enclosing scope, so a
  705: C<BEGIN> block earlier in the same file could still take a reference to
  706: the unwrapped sub.
  707: 
  708: =item C<enforce> mode: C<can()> leaks private method existence
  709: 
  710: In C<enforce> mode the original sub is replaced by a wrapper closure, so
  711: C<< ->can('_helper') >> returns the wrapper (a true value) even to callers outside
  712: the owner package.  In C<namespace> mode the stash entry is deleted entirely,
  713: so C<< ->can >> correctly returns C<undef>.  A future release may inject a
  714: caller-aware C<can()> override into each class that uses C<enforce> mode,
  715: returning the coderef only when the caller is the owner package and C<undef>
  716: for everyone else.
  717: 
  718: =item UNIVERSAL namespace pollution
  719: 
  720: The C<:Private> attribute is installed in C<UNIVERSAL>, which is
  721: intentional (any package can use it after a single C<use>), but it does
  722: introduce C<UNIVERSAL::Private> into the global namespace.
  723: 
  724: =back

  756: =head1 FORMAL SPECIFICATION
  757: 
  758: The following Z-notation schemas formally specify the C<CheckAccess>
  759: operation and C<import>.
  760: 
  761: =head2 C<CheckAccess>
  762: 
  763:     -- Type abbreviations
  764:     Package  == seq CHAR     -- a non-empty Perl package name string
  765:     SubName  == seq CHAR     -- a Perl identifier string
  766: 
  767:     -- Private-access predicate (strictly owner only -- no isa expansion)
  768:     permitted : Package x Package -> BOOL
  769:     forall caller, owner : Package .
  770:         permitted(caller, owner) <=> caller = owner
  771: 
  772:     -- System state
  773:     +-Registry-------------------------------------------+
  774:     | private   : P (Package x SubName)                  |
  775:     | bypass    : BOOL                                    |
  776:     | config    : { mode : seq CHAR,                      |
  777:     |               harness_bypass : BOOL }               |
  778:     | pkg_mode  : Package -+> seq CHAR                   |
  779:     +----------------------------------------------------+
  780: 
  781:     -- Initial state
  782:     +-InitRegistry---------------------------------------+
  783:     | Registry                                           |
  784:     |----------------------------------------------------|
  785:     | private   = {}                                     |
  786:     | bypass    = false                                  |
  787:     | config    = { mode |-> 'namespace',                 |
  788:     |               harness_bypass |-> true }             |
  789:     | pkg_mode  = {}                                     |
  790:     +----------------------------------------------------+
  791: 
  792:     -- Bypass predicate
  793:     bypass_active(R) <=>
  794:         R.bypass or (R.config.harness_bypass and HARNESS_ACTIVE)
  795: 
  796:     -- Access check: no state change
  797:     +-CheckAccess----------------------------------------+
  798:     | Xi-Registry                                        |
  799:     | caller? : Package                                  |
  800:     | owner?  : Package                                  |
  801:     | name?   : SubName                                  |
  802:     | ok!     : BOOL                                     |
  803:     |----------------------------------------------------|
  804:     | (owner?, name?) in private                         |
  805:     | ok! <=> bypass_active or permitted(caller?, owner?)|
  806:     +----------------------------------------------------+
  807: 
  808:     -- Violation (croak case):
  809:     --   not ok! =>
  810:     --   croak("name?()" ++ " is a private subroutine of " ++ owner?
  811:     --         ++ " and cannot be called from " ++ caller?)
  812: 
  813:     -- Key difference from Sub::Protected:
  814:     --   permitted(caller, owner) <=> caller = owner   (identity only)
  815:     -- vs Sub::Protected:
  816:     --   permitted(caller, owner) <=> owner in anc(caller)   (ISA chain)
  817: 
  818: =head2 import
  819: 
  820:     -- Valid identifier predicate
  821:     valid_id : SubName -> BOOL
  822:     valid_id(n) <=> n =~ /\A[_a-zA-Z]\w*\z/
  823: 
  824:     -- Compile phase: CHECK has run, and code is still being compiled
  825:     post_check  : BOOL
  826:     compiling   : BOOL       -- true while $^S is undefined
  827: 
  828:     -- The mode that applies to a package's subs
  829:     mode_for(p) = pkg_mode(p)   if p in dom pkg_mode
  830:                 = config.mode   otherwise
  831: 
  832:     -- Options (hashref first): sets the caller's mode only
  833:     +-ImportOptions-------------------------------------+
  834:     | Delta-Registry                                    |
  835:     | mode? : seq CHAR                                  |
  836:     |---------------------------------------------------|
  837:     | mode? in { 'namespace', 'enforce' }               |
  838:     | pkg_mode' = pkg_mode (+) { caller |-> mode? }     |
  839:     | config' = config                                  |
  840:     +---------------------------------------------------+
  841: 
  842:     -- Pre-condition (declarative form)
  843:     +-ImportPre-----------------------------------------+
  844:     | mode_for(caller) = 'enforce'                      |
  845:     | forall n in subs . valid_id(n)                    |
  846:     +---------------------------------------------------+
  847: 
  848:     -- Post-condition (before CHECK): queue for the CHECK block
  849:     +-ImportPost_PreCheck-------------------------------+
  850:     | not post_check                                    |
  851:     |---------------------------------------------------|
  852:     | pending' = pending ++ < (caller, n) | n in subs > |
  853:     +---------------------------------------------------+
  854: 
  855:     -- Post-condition (after CHECK, at run time): wrap now
  856:     +-ImportPost_RunTime--------------------------------+
  857:     | post_check and not compiling                      |
  858:     | forall n in subs . defined(caller, n)             |
  859:     |---------------------------------------------------|
  860:     | forall n in subs .                                |
  861:     |   stash'(caller, n) = wrapper(caller, n)          |
  862:     +---------------------------------------------------+
  863: 
  864:     -- Post-condition (after CHECK, while compiling): wrap at the
  865:     -- end of the enclosing scope S
  866:     +-ImportPost_Deferred-------------------------------+
  867:     | post_check and compiling                          |
  868:     |---------------------------------------------------|
  869:     | at end_of_scope(S) :                              |
  870:     |   (forall n in subs . defined(caller, n)) =>      |
  871:     |     forall n in subs .                            |
  872:     |       stash'(caller, n) = wrapper(caller, n)      |
  873:     |   (exists n in subs . not defined(caller, n)) =>  |
  874:     |     croak at the "use" line                       |
  875:     +---------------------------------------------------+
  876: 
  877:     -- In every case, a sub that is not defined when wrapping is
  878:     -- attempted croaks:
  879:     --   "Sub::Private: " ++ caller ++ "::" ++ n ++ " is not defined"
